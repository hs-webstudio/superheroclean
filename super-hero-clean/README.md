# Super Hero Clean

Site estático (HTML/CSS/JS) de higienização de estofados, carpetes e veículos em Porto Alegre e região.

## Publicar no GitHub Pages
Settings > Pages > Deploy from a branch > main / (root).

## Editar
- Preços: objeto `D` no final do `index.html`
- WhatsApp: variável `N`
- Imagens: pasta `assets/`
